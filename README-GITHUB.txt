VELVET & VIVID CREATIONS — FLAT GITHUB PAGES PREVIEW

Every file in this package sits directly at the ZIP root. No folders,
no server, and no build step are required.

1. Extract this ZIP before uploading. GitHub does not unpack ZIP uploads.
2. Visit https://github.com/runrobbie/Velvet-VividCreations
3. Select Add file > Upload files.
4. Select ALL seven extracted files and upload them into the repository root.
   Replace existing index.html, styles.css, site.js, and favicon.svg.
5. Keep your existing velvet-vivid-hero.webp and velvet-texture.webp in
   the repository if they are present. The approved hero image is used
   automatically; hero-fallback.svg is provided as a safety fallback.
6. Commit changes to main. In Settings > Pages, use Deploy from branch,
   main, /(root). Then open:
   https://runrobbie.github.io/Velvet-VividCreations/

This is a STATIC, INTERACTIVE DEMONSTRATION ONLY. All sample appointments,
clients, invoices, services, and inquiries live in local browser storage.
They can be changed, explored, exported, and reset using the preview controls.
Bookings are not real. There is no backend, authentication, payment processing,
SMS, or email delivery in the GitHub Pages version. The complete original
Python application must be deployed to a suitable backend host for that.

Root-relative asset paths have been changed to relative paths so GitHub
Pages serves the CSS and JavaScript correctly under /Velvet-VividCreations/.

No actual sensitive client data should be entered into this publicly hosted
preview. Use sample names, emails, dates, and images only.
